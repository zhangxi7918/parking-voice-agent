# Tech Selection Artifacts

This directory contains scripts, examples, recordings, and benchmark outputs used during realtime voice provider evaluation.

Current contents:

- `*-smoke-test.local.mjs`: provider-specific realtime API smoke tests.
- `voice-agent-benchmark.local.mjs`: benchmark harness for parking-gatekeeper voice agent scenarios.
- `VOICE_AGENT_BENCHMARK.md`: notes for running and interpreting the benchmark.
- `test-audio/`: recorded audio samples used by benchmark scenarios.
- `benchmark-results/`: generated benchmark outputs.
- `gemini-live-api-examples/`: upstream/local Gemini Live reference examples.

Keep production application code outside this directory.
